# Contributing to Chess & Chains

Chess & Chains is at foundation stage. Open an issue to discuss larger changes; obtain owner approval for licensing, feature scope and design brand changes. Use focused branches, include tests/documentation and follow [AGENTS.md](AGENTS.md). Never contribute code or art copied without permission.

## Checks

```sh
python -m unittest discover -s tests -v
python scripts/verify_starter.py
```

Document tested platforms, behavior, remaining limitations, dependency provenance and new license obligations. Submitted material must not contain secrets, personal information or unlicensed chess art. No contribution implies automatic release approval.

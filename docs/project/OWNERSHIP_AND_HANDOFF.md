# Ablage-/Owner-Vertrag

**GitHub:** alleiniger veröffentlichter Quell-/Dokumentationsstand nach erfolgreichem Push. **OneDrive:** optional für private Grafik-Master, Rohdaten und Arbeitsstände; Ordnerpfad nur nach Angabe des Owners. Keine dynamisch erratenen Cloud-Pfade und kein stilles Kopieren zwischen Repo-Klonen.

- Öffentlich: README, freigegebener Code, freigegebene Originaldesign-Dateien, Tests und Produktdokumentation.
- Lokal/private Cloud: Lizenz-unklare Fonts/Designs, fremde Bilder, private Markenentwürfe, persönliche Nutzerdaten, lokale Build-Artefakte, größere Rohdatensätze.
- Große freigegebene Runtime-Assets: Git LFS oder versionierte Download-/Paketstrategie erst nach Abwägung; **nicht** blind in Git committen.
- Die Verantwortung für Personen-, Unternehmens-, Urheber- und Markenangaben ist Q-015; keine Namensannahmen.
- Neue KI-Agenten starten mit `START_HERE.md`, `AGENTS.md`, SSOT-Index, letzter Handover-Datei und **aktuellem** `git status`/Remote-Commit.
